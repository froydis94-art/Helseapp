            only prompt construction differs. Manual one-shot only; no Run All

            Interpretation guide: If A succeeds while B/C/D fail, dense
            policy/safety wording is the likely trigger. If A and C succeed but
            B/D fail, preview-context wording is implicated. If only D fails,
            pre-017C wording is implicated. If all fail, the source image or
            model/provider path is more likely than prompt isolation. Provider
            outcomes can still vary run-to-run even with a fixed seed.
